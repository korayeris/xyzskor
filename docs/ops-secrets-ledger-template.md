# XYZSKOR ops / secrets ledger template

Bu dosya şablondur. Gerçek secret değerleri buraya yazılmaz. Git dışında doldurulur.

## Provider kayıt şablonu

### 1. Provider adı

- örnek: Sportmonks / X Developer / Supabase / Google Cloud / Domain Registrar

### 2. Konsol URL

- panel linki

### 3. Teknik sahip

- isim
- e-posta
- telefon

### 4. Finansal sahip

- isim
- e-posta

### 5. Billing bilgisi

- plan adı
- aylık / yıllık
- yenileme tarihi
- harcama limiti

### 6. Secret / token kayıtları

- secret adı
- hangi ortamda kullanılıyor
- son rotation tarihi
- bir sonraki rotation tarihi

### 7. Recovery

- 2FA recovery code konumu
- yedek admin hesabı
- erişim kaybı durumunda izlenecek akış

## Doldurulacak provider listesi
